➕ Add a game for everyone

To make a game appear for every visitor, add its HTML file to this GitHub repository. A browser-only upload button cannot publish files to GitHub.

  1. Open your nexus-arcade repository on GitHub.
  2. Choose Add file → Upload files.
  3. Upload the new game's .html file into the main folder (the same folder as index.html).
  4. Click Commit changes.
  5. Open index.html on GitHub, click the pencil to edit, and copy a game card pattern from the README, changing its title and filename.
  6. Commit that change. After GitHub Pages updates, everyone can see the new game.

Tip: Keep each game and its supporting image/audio files together in the repository. If a game uses folders, upload those folders too.
